SHARED STYLE — applies to all 10 illustrations:
Semi-flat vector illustration with confident 2px ink outlines. Bold, warm, editorial feel — not corporate stock art, not cartoonish. Colour palette strictly limited to: #FF5500 orange (energy, clothing accents, brand moments), #111111 near-black (outlines, ink, shadows), #FAFAF8 off-white (backgrounds, skin highlights), #1D4E5F deep teal (shelving, backgrounds, structural elements), #FFB830 warm amber (product highlights, star moments, secondary accents), plus two skin tones — #C8845A warm medium and #F0C8A0 warm light. No other colours. Flat fills only — no gradients, no soft airbrush shading, no drop shadows with blur. Subtle grain/paper texture overlay allowed. Characters are diverse Singapore/Southeast Asian (Chinese, Malay, Indian mix; mixed gender; ages 20–40), always mid-action — never static or posed. Products are generic bold FMCG items (bottles, cans, boxes, tubes) — no real brand logos or readable text visible. Every illustration must be free of embedded text, labels, watermarks, or UI elements. White background on all images.

Avoid: stock illustration clichés, neon colours, gradients, soft airbrush shading, gradient mesh backgrounds, flat gradient fills, text baked in, AI-warped anatomy, corporate clip-art poses, thumbs-up or pointing poses, same skin tone on all characters, oversaturated colours, generic emoji faces.

# HOW TO EXPORT FROM STITCH AND SEND TO CLAUDE

1. **In Stitch:** When you are satisfied with an image, hover over it in the canvas — a download arrow icon appears. Click it to download as PNG.

2. **Naming:** Rename each file to match the illustration name in these prompts (e.g. `hero-promoter-main.png`, `scene-roadshow.png`, `inv-claw-machine.png`). This is important — it tells Claude exactly where each image goes on the website.

3. **Export folder:** Create a folder called `stitch-exports` anywhere convenient (Desktop is fine). Put all downloaded PNGs in it.

4. **Sending to Claude:** Two options:
   - **Option A (recommended):** Copy/move the entire `stitch-exports` folder into `/Users/seaheevann/Claude Coding/FMCG Website/assets/img/` — then start a new Claude Code session and say "stitch exports are in assets/img/ — please wire them into the site." Claude will find them and do the rest.
   - **Option B:** Start a new session and drag-and-drop the images directly into the Claude Code chat window (Claude can read images you upload).

5. **Format note:** PNG is fine. Claude will convert to `.webp` during the build for better performance.

6. **Do them in rounds:** Generate Round 1 first — get the style right before moving to Round 2. If the style feels off, adjust the SHARED STYLE block and regenerate before doing the icon set.
